## A fresh start for desktop listening

Spoty is a new native music app for people who want quick access to their
Spotify library and a more thoughtful desktop experience. The project is
being developed for casual listening and detailed playback control alike.

The current codebase provides the starting point. The Spoty product identity,
interface, and packaging are being shaped as the rebuild progresses.

## Follow along

Visit the [Spoty repository](https://github.com/efeio/spoty) for source code,
development updates, and future release information. Read the
[product brief](https://github.com/efeio/spoty/blob/main/PRODUCT.md) and
[design direction](https://github.com/efeio/spoty/blob/main/DESIGN.md) for the
project's current goals.
